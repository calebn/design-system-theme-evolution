# Raw Design Context

This directory stores design context responses from the Figma Desktop MCP `get_design_context` tool.
Each file contains the raw TypeScript/React code generated by Figma for a specific component frame.

## Files

Files are named `{figma-id-with-hyphens}.txt`, e.g.:
- `1770-9407.txt` — Star
- `1770-9371.txt` — Reviews

## Capturing Context

To re-capture or extend, use the Figma Desktop MCP `get_design_context` tool in Cursor:

```
get_design_context({ nodeId: "1770:9407", clientLanguages: "typescript", clientFrameworks: "react", artifactType: "REUSABLE_COMPONENT" })
```

Save the text response to `raw/design-context/{id-with-hyphens}.txt`.

For large components (e.g. Button at 1623:3480), the response will be truncated XML metadata
rather than generated code. Sublayer-level calls are needed for those.

## What the Generated Code Tells Us

- **Prop types**: TypeScript `type` declarations reveal all variant axes and allowed values
- **Nested components**: Component function calls (e.g. `<Star .../>`) reveal actual dependencies
- **Spacing/sizing**: Tailwind classes show exact pixel values and auto-layout behavior
- **Token references**: CSS variable references like `var(--headings/h5)` indicate token usage
